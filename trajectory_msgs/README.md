# `trajectory_msgs` — 机器人运动轨迹消息包

定义机械臂关节空间轨迹及多自由度全身/飞行器空间轨迹的标准数据格式，是 `ros2_control` 轨迹控制器与 `MoveIt 2` 的核心通信接口。

## 消息列表（`msg/`，共 4 个）

| 消息名称 | 简介 |
| :--- | :--- |
| [`JointTrajectory`](./msg/JointTrajectory.md) | 关节空间运动轨迹序列 |
| [`JointTrajectoryPoint`](./msg/JointTrajectoryPoint.md) | 关节轨迹的单个时间步路点 |
| [`MultiDOFJointTrajectory`](./msg/MultiDOFJointTrajectory.md) | 多自由度空间运动轨迹序列 |
| [`MultiDOFJointTrajectoryPoint`](./msg/MultiDOFJointTrajectoryPoint.md) | 多自由度轨迹的单个时间步路点 |
