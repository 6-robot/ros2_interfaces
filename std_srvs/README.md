# `std_srvs` — 标准通用服务接口包

包含无需自定义复杂请求结构的最基础服务接口，适用于节点启停、复位、标定触发和布尔状态切换。

## 服务列表（`srv/`，共 3 个）

| 服务名称 | 简介 |
| :--- | :--- |
| [`Empty`](./srv/Empty.md) | 空请求与空响应服务 |
| [`SetBool`](./srv/SetBool.md) | 设置布尔开关状态服务 |
| [`Trigger`](./srv/Trigger.md) | 无参触发并返回状态服务 |
