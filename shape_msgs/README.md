# `shape_msgs` — 基础三维几何体消息包

定义用于环境碰撞检测、障碍物建模和 MoveIt 2 规划场景的基础三维几何实体、无限平面与三角网格结构。

## 消息列表（`msg/`，共 4 个）

| 消息名称 | 简介 |
| :--- | :--- |
| [`Mesh`](./msg/Mesh.md) | 三维三角网格模型 |
| [`MeshTriangle`](./msg/MeshTriangle.md) | 三角网格的单个三角面片顶点索引 |
| [`Plane`](./msg/Plane.md) | 三维空间无限平面方程 |
| [`SolidPrimitive`](./msg/SolidPrimitive.md) | 基础三维规则几何实体（立方体/球/圆柱/圆锥/棱柱） |
